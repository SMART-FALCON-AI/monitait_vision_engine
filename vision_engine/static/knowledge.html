This system as an MCP server

External agents can query this production line and its documents. Point an MCP client at:

http://<this-host>:4445/mcp

Read tools are always available. Write tools (open issue, append to issue, upload document) require KB_MCP_ALLOW_WRITE=true. Changing procedures, pipelines or the ejector is never exposed over MCP — those go through the approval flow.

Connect an external MCP server

ERP, MES, maintenance/CMMS, ticketing, document management. Its tools are merged into the assistant so one conversation can span the line and your business systems.
