🎨 Colour Target (heatmap baseline)

Per-camera CIE L*a*b* values used as the "gold standard" by the heatmap's 🎯 Target baseline button on the Charts tab. The heatmap colours each cell by its ΔE against this target. Leave a camera's L=0 to skip it.

Tip: set L to the median brightness you'd expect for that camera under nominal lighting (rough range 30–80). Set a and b near 0 unless your product has a strong colour tint.

📊 Quality Scoring

score_scale_factor is the gain knob on impact-to-score conversion: score = 100 × (1 − min(1, impact_per_unit × factor)). Higher factor = harsher scoring. Default 1.0 makes most shipments score ~99.9; the auto-calibrator picks a value that lands the median recent shipment at ~85.

📏 Encoder Calibration

Tell the system what unit your line counts in and how many encoder pulses equal 1 of them. Every length display in the UI — dashboard tile, quality strip, Score-per-shipment chart, Camera × Length axis — uses this pair.

Examples:
 • Fabric line: Meter, 1000 pulses per 1 Meter → dashboard shows "12.3 Meter"
 • Roll-batch line: Batch, 50000 pulses per 1 Batch → dashboard shows "0.2 Batch"
 • Glass line: Cubic Meter, 300 pulses per 1 Cubic Meter

Leave the pulses field blank/0 if you just want raw counts with your custom label.

🎨 Parent Object Color Check

Tracks colour drift by measuring CIELAB (L*a*b*) on the parent object's bounding box every frame. Turn this on after designating one class as Role: 🌳 Parent in the Process tab — MVE will measure that class's largest bbox. When off, the chart tab hides the colour heatmap and its baseline/phase pickers. Baseline is per (camera, phase).
